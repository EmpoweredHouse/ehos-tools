# Code of conduct

This page tells you which rules of behaviour apply in ehos-tools, and how to report a breach.
The rules apply in the issues, the pull requests, the reviews and each other place of this
repository.

## The rules

ehos-tools uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It says which behaviour the community expects, which behaviour it does not accept, and what the
maintainers can do when a person breaks the rules.

## Report a breach

1. Open the menu (**…**) of the comment, the issue or the pull request.
2. Select **Report content**, then **Report to repository admins**.
3. Describe what occurred, and add links to the other comments that it concerns.

Only the administrators of the repository see the report.

If the breach concerns a maintainer, or the content is not a comment, select **Report to GitHub
support** instead. GitHub then decides the report.
