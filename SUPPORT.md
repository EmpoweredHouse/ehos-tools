# Get help

This page tells you where to ask a question about ehos-tools, and where to report a problem.

| You want to | Go to |
| --- | --- |
| Install `ehosctl` or create an application | [README.md](README.md) and [the golden path](docs/golden-path.md) |
| Know what a command of `ehosctl` does | [the command pages](packages/ehosctl/docs/commands) |
| Report a bug | [a new issue](https://github.com/EmpoweredHouse/ehos-tools/issues/new/choose), with the bug form |
| Ask for a change or a new feature | [a new issue](https://github.com/EmpoweredHouse/ehos-tools/issues/new/choose), with the feature form |
| Ask a question | [a new issue](https://github.com/EmpoweredHouse/ehos-tools/issues/new/choose), with the question form |
| Report a security problem | [SECURITY.md](SECURITY.md); do not open a public issue |

Before you open an issue, search the [open and closed issues](https://github.com/EmpoweredHouse/ehos-tools/issues?q=is%3Aissue).
Another person can have the same problem.

Remove tokens, keys, passwords and sign-in links from each log and each command that you put in an issue. An
issue is public.
